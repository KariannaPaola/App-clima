App Clima Actual

Aplicación web que muestra el clima de la ubicación actual del usuario y permite buscar el clima de cualquier ciudad o ubicación mediante un buscador.

Live Demo
https://app-clima-puce.vercel.app/

Tech Stack
React
Tailwind CSS
Consumo de API de clima

Features
Obtener el clima de la ubicación actual del usuario.
Buscar el clima de cualquier ciudad o ubicación.
Interfaz simple y rápida para consultar el clima.

Installation
git clone https://github.com/KariannaPaola/App-clima
cd App-clima
npm install
npm run dev

What I Learned
Consumo de APIs REST.
Manejo de estado en React.
Integración de datos externos en una interfaz web.
